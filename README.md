# Overview
A simple chess GUI built with Tkinter

# How to Run

This project uses a Python virtual environment (venv).  
Below are instructions for Windows, macOS, and Linux.

## Windows

1. Create virtual environment:
   python -m venv venv

2. Activate it:
   venv\Scripts\activate

3. Install dependencies:
   pip install -r requirements.txt

4. Run the program:
   python main.py


## macOS

1. Create virtual environment:
   python3 -m venv venv

2. Activate it:
   source venv/bin/activate

3. Install dependencies:
   pip install -r requirements.txt

4. Run the program:
   python3 main.py


## Linux

1. Create virtual environment:
   python3 -m venv venv

2. Activate it:
   source venv/bin/activate

3. Install dependencies:
   pip install -r requirements.txt

4. Run the program:
   python3 main.py
